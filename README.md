# KernelSU 四系适配检测（实验版）

本仓库当前先建立 Android APK 的设备信息与现有 Root 状态检测外壳。

## 当前功能
- 显示 Android 版本、设备型号、ABI 和内核版本
- 检查系统是否已经存在可用的 `su`
- 输出适配验证提示

## 安全边界
此版本**不是临时 Root 漏洞利用器**，不会执行上传的未知提权脚本、加载未经核验的内核模块、修改内核内存或刷写 boot/vendor_boot。仅凭“4.19.191+”和“MT6833”不能证明模块 ABI、符号地址、结构体偏移与目标设备一致。未完成目标设备专属验证前，不会启用提权入口。

上传的 `ksu` 文件不会被自动打包或执行。请勿在主力设备上运行未经验证的内核载荷。

## 构建
仓库配置了 GitHub Actions：推送到 `main` 或手动运行 **Build Android APK**，构建 `app-debug.apk` 并上传为 Actions artifact。

## 目标设备记录
- 用户目标：OPPO A55 5G / PEMM00
- 用户提供的系统信息：Android 13、Linux 4.19.191+
- SoC/设备树与实际内核构建配置仍需从设备报告确认
